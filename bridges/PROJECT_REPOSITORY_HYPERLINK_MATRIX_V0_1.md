## Promotion rule

No entry in this matrix is promoted solely because it is hyperlinked. A repository receives a formal bridge only after:
1. its exact current default-branch head is read;
2. the relevant local authority surface is identified;
3. a dedicated branch is created from that head;
4. derivation/code/tests preserve the local epistemic firewall;
5. hosted/local validation is recorded;
6. the source-owned dependency export is updated before any corresponding FPDG federation promotion.
